# TaskForge 2.0 🚀

### Forged for Progress.

**TaskForge** is a productivity dashboard designed to help users organize their responsibilities, manage deadlines, build consistent habits, and track their progress.

🔗 **Live Application:** https://lincon-web.github.io/TaskForge/

---

## 📌 About the Project

TaskForge was built to make personal productivity more organized and manageable. It provides a central space for educational, professional, and personal tasks, helping users focus on what needs to be done next.

The philosophy behind TaskForge is simple:

> **Big moves are built from small wins. Show up, complete the next task, and keep moving. What feels small today can become the foundation of something extraordinary tomorrow.**

## ✨ Features

* **Task Management:** Create, edit, complete, and delete tasks.
* **Task Organization:** Categorize tasks into Education, Work, and Personal.
* **Priority Management:** Organize tasks according to their importance.
* **Search and Filtering:** Find tasks and filter them to focus on specific work.
* **Deadline Tracking:** Set due dates and times for tasks.
* **Reminders:** Receive deadline notifications while the application is running and notifications are available.
* **Productivity Insights:** Track task completion and review productivity statistics.
* **Authentication:** Sign in and register using the supported authentication system.
* **Cloud Synchronization:** Store and synchronize tasks through Supabase.
* **Guest Mode:** Use local task storage without signing in.
* **Responsive Design:** Adapt the interface to different screen sizes.
* **Sharing:** Share TaskForge through social platforms or copy its link.
* **Progress-Focused Design:** A dedicated splash screen, motivational messaging, and an About section.

## 💻 Running the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/lincon-web/TaskForge.git
   ```

2. Open the project folder:

   ```bash
   cd TaskForge
   ```

3. Open `index.html` using a local development server, such as the Live Server extension in Visual Studio Code.

4. To use authentication and cloud synchronization, configure the Supabase project settings using the required public client credentials.

   **Security note:** Never expose Supabase service-role keys, private API keys, or other secrets in frontend code.
